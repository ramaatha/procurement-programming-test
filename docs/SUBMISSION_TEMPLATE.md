### Akun demo

| Username           | Peran       | Kegunaan                                                 |
| ------------------ | ----------- | -------------------------------------------------------- |
| `demo_admin`       | Admin       | Membaca dokumen serta mengelola akun dan vendor.         |
| `demo_pemohon`     | Pemohon     | Membuat dan mengajukan permintaan.                       |
| `demo_approver`    | Approver    | Menyetujui, meminta revisi, menolak, atau mengakhiri PO. |
| `demo_procurement` | Procurement | Mengelola penawaran, memilih vendor, dan menerbitkan PO. |
| `demo_penerima`    | Penerima    | Mencatat penerimaan barang atau jasa.                    |

Password terbaru diberikan bersama informasi akses demo melalui kanal privat.

### Alur demo aplikasi

1. Buka aplikasi demo dan masuk dengan akun sesuai peran yang ingin dicoba.
2. Untuk memulai alur baru, gunakan `demo_pemohon`, lalu pilih **Buat Permintaan**.
   Isi manual atau gunakan **Bantu Isi dengan AI** secara opsional; periksa hasil sebelum diterapkan.
3. Simpan draf, lengkapi kebutuhan, lalu ajukan permintaan.
4. Lanjutkan dengan urutan **Approver → Procurement → Penerima** menggunakan dokumen yang sama.
   Logout sebelum berganti akun.
5. Ikuti panduan pengguna untuk contoh isian, penerimaan bertahap, riwayat, dan cetak PO.

Gunakan data contoh. Data demo digunakan bersama; buat judul permintaan yang berbeda
agar transaksi mudah dikenali. Bantuan AI bersifat opsional dan mengikuti limit pemakaian;
input manual tetap tersedia.
