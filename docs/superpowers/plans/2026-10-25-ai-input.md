# Optional AI Draft Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Add optional text/image Qwen assistance to new request drafts while manual entry remains primary.

**Architecture:** A requester-only POST endpoint validates input, reserves a bounded quota outside the business database transaction, calls fixed Groq chat completions, and returns validated suggestions. JavaScript previews these suggestions and only fills blank manual fields on explicit Apply; normal save/submit services remain authoritative.

**Tech Stack:** Existing Django templates/SQLite/JavaScript; Python stdlib HTTP; pinned Pillow for image verification and metadata-stripping re-encoding.

**Spec:** Approved conversation design, 25 October 2026, OPT-01 in PRD. User explicitly approved implementation and requested token conservation.

## Global Constraints

- Manual form works with no API key and no JavaScript. AI never saves/submits/approves/orders.
- qwen/qwen3.8-27b, reasoning_effort=none, max_completion_tokens=1200, one request without retries; <=1500 input characters, one JPG/PNG <=2MiB and <=12MP, maximum10 suggested items.
- Private key file independent of existing hosting secret file. No credentials/documents logged or packaged. No live inference without configured key and deliberate user action.
- Atomic SQLite quota file inside private DATA_DIR, metadata only:10 global attempts/day,5/user/day,1 active request,60-second lease. Failed upstream attempts count. No main-model migrations.
- Numeric strings only; server validates strict canonical qty/money and source-null fields. No floating-point prices or invented estimates.
- Preserve incumbent Operations Desk UI, no overflow at320/390/768/1440, keyboard/aria states, no silent overwrites.
- All Git writes remain with user. Implementation performed via explicit staged copies, isolated test app/database, no worktree/commit tooling that mutates Git.

## Review Focus

- Late/cancelled AI responses never overwrite newer form edits or results.
- Malformed/injected model text cannot render HTML, populate hidden tokens, or bypass business validation.
- Invalid image/oversize/error never reaches provider and leaves manual fields intact.
- Parallel requests cannot race global/user quotas; network waits never hold business locks.
- Token conservation: no thinking/retry/history; automated tests consume zero provider tokens.
